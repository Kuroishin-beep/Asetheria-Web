# Asetheria-Web — audit & roadmap

Full scan of the frontend, backend, data pipeline and content, measured against
three references the codex should feel like:

- **Notion**: pages that read beautifully, edit without friction and never
  lose work; structure (properties, outlines, templates) without ceremony.
- **Superhuman**: everything reachable from the keyboard in under two seconds;
  a command bar that runs actions, not just search.
- **Obsidian**: the graph *is* the product — `[[links]]`, backlinks, aliases,
  unlinked mentions, hover previews, local graphs.

Status key: ✅ fixed / built in this pass · 🟡 partly there · ⬜ proposed

## 2. Built in this pass

### Superhuman — keyboard first
- ✅ **Command bar runs actions**: an empty Ctrl/Cmd+K lists commands; typing
  filters commands *and* entries together; DM-only commands hidden from players.
- ✅ **Chords**: `g h` home · `g s` search · `g g` graph · `g n` NPCs · `g q`
  quests · `g d` deities · `g r` dice · `g t` tables · `g a` archive · `g x`
  admin · `g p` players & access · `c` new entry · `e` edit this page.
- ✅ **`?` shortcut sheet**, generated from the same table as the palette, so
  they never drift (`src/lib/shortcuts.ts`).
- ✅ **Ctrl/Cmd+S saves** in the editor.

### Obsidian — the graph
- ✅ **`[[` autocomplete** in the editor.
- ✅ **Aliases** ("Also known as"): any `[[spelling]]` resolves, in pages and in
  the graph.
- ✅ **Hover previews**: wiki links carry the target's summary.
- ✅ **Unlinked mentions** (DM): pages that name this one without linking it,
  each one click from its editor. Linked and unlinked are now distinct edge
  types (`mentions` vs `named`).

### Notion — reading and writing
- ✅ **Write / Preview** tabs.
- ✅ **Draft recovery**: unsaved text survives a closed tab or crash.
- ✅ **Page outline** ("On this page") on pages with 3+ headings; headings get
  stable anchors (`#sec-…`) that can be linked.

## 3. Roadmap (proposed, highest value first)

### Next up
1. ⬜ **Local graph on every entry page** (Obsidian): the 1–2 hop neighbourhood
   in the sidebar, reusing `graph-view.tsx` with a filtered edge set.
2. ⬜ **Searchable parent picker**: today a `<select>` of up to 1,000 entries.
   Use the `[[` autocomplete component as a combobox.
3. ⬜ **Inline property editing** (Notion): click a property on the page to edit
   it in place, with no round trip through the full form.
4. ⬜ **Templates per kind** (Notion): "New NPC" pre-fills headings (Appearance,
   Motivation, Secrets → DM notes). `/codex/new?kind=` already knows the kind.
5. ⬜ **Recently viewed + pinned** in the sidebar and as the palette's empty
   state (Superhuman's "jump back").
6. ⬜ **Session log flow**: a "Start session" command that creates the log with
   date and number, then `[[links]]` everything mentioned at the table.

### Later
7. ⬜ **Block references / transclusion**: `![[Entry#Section]]` embeds a section,
   using the new heading anchors.
8. ⬜ **Tag pages and tag hierarchy** (`tag/subtag`): a page per tag listing
   entries and backlinks.
9. ⬜ **Revision diff view**: revisions exist; show *what* changed, not just when.
10. ⬜ **Slash commands** in the editor (`/table`, `/secret`, `/roll 1d20`).
11. ⬜ **Player-facing "what's new"**: entries revealed or granted since the
    player's last visit.
12. ⬜ **Offline read mode**: a PWA cache of what the player may read, for tables
    with bad wifi.
13. ⬜ **Design-system migration** to shadcn/ui + Motion per `CLAUDE.md`.

### Applying to production (Neon)

Run in this order with `DATABASE_URL` pointing at Neon:

```bash
psql "$DATABASE_URL" -f scripts/sql/setup.sql          # player_search_vector + pgvector index
npx tsx scripts/import-codex-file.ts data/foundry-world.json --fill-empty
npx tsx scripts/import-codex-file.ts data/lore-population.json --fill-empty
npx tsx scripts/merge-duplicates.ts --apply
npx tsx scripts/import-codex-file.ts data/city-locations.json --fill-empty
npx tsx scripts/rebuild-links.ts
npm run embeddings:generate
```

All seven steps are idempotent and none deletes anything.
