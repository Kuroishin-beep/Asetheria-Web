**Call to Action** (Hard hook)

Use a strong verb.  If you’re running a one-shot or the first session of a campaign, skip the soft hooks and start with a clear call to action.

- **Expanding or Condensing the Adventure**
    
    If you want to make a **one-shot**, start with the hard hook and cut out a few encounters.
    
    If you want to make a longer adventure:
    
    - Add more locations. Give each location:
        - A cool, unique thing
        - Challenges:  physical, mental, social, or ethical
        - Space to explore
    - Make characters’ goal multiple steps
        - Use strong action verbs
        - Make it clear how one goal leads to the next
        - e.g., 1) Find the key, 2) Find the lock, 3) Use the lock and the key
    - Give the villain a henchman or two
        - 1) Defeat mini-boss, 2) Defeat mini-boss, 3) Confront final boss
    - The B Plot: Run two adventures simultaneously. Only give one a hard hook and let the other simmer on the back burner until the right time.
